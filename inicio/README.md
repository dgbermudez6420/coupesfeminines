# Atlas visuel des coupes féminines — France

## Installation
Extraire le ZIP et placer `index.html` et le dossier `assets/` côte à côte à la racine de l’hébergement. Aucun outil de compilation n’est requis. Les chemins des images, styles et scripts sont relatifs.

## Paiement
Le bouton « Obtenir mon Atlas visuel » ouvre :
https://pay.hotmart.com/H108233973U?checkoutMode=10
